# C++ Programming Code Collection

A collection of basic C++ programming examples, practice programs, and exercises.

## Files

- [`firstprog.cpp`](firstprog.cpp): Basic I/O demonstration with favorite number prompt.
- [`challangeprob.cpp`](challangeprob.cpp): Practice challenge with input, variable storage, and formatted output.
- [`displaynum.cpp`](displaynum.cpp): Multiple data type input and output (`int` and `double`).
- [`carpet_cleaning_rate.cpp`](carpet_cleaning_rate.cpp): Frank's Carpet Cleaning Service estimate and tax calculation.
- [`EUROStoUSD.cpp`](EUROStoUSD.cpp): Currency converter from Euros to USD.
- [`switch.cpp`](switch.cpp): Grade threshold requirement checker using `switch` statement.

## How to Compile & Run

Using G++:
```bash
g++ filename.cpp -o filename.exe
./filename.exe
```
